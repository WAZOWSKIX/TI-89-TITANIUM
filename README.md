Power Flow Analysis Software (TI-89 Titanium)OverviewA standalone C-based numerical solver developed for the TI-89 Titanium platform (TIGCC environment). The software computes the steady-state operating point (Voltage Magnitude $|V|$ and Phase Angle $\delta$) of small-scale power systems by solving the non-linear power flow algebraic equations.Implemented AlgorithmsNewton-Raphson (NR):Formulation: Polar coordinates.Jacobian Matrix: Computes the full Jacobian matrix ($J$) with exact partial derivatives ($\partial P/\partial \theta$, $\partial P/\partial V$, $\partial Q/\partial \theta$, $\partial Q/\partial V$).Solver: Uses Gaussian elimination to solve the linear system $J \cdot \Delta x = \Delta M$ (Mismatch) at each iteration.Convergence: Quadratic convergence characteristics (typically 3-5 iterations).Gauss-Seidel (GS) & Accelerated GS:Method: Iterative point-by-point solution using the standard fixed-point iteration formula.Acceleration: Implements an acceleration factor ($\alpha$) to extrapolate voltage corrections: $V_{new} = V_{old} + \alpha(V_{calc} - V_{old})$.PV Bus Handling: Explicitly calculates reactive power injection ($Q_{gen}$) to maintain voltage magnitude constraints before angle updates.Data Input InterfaceAdmittance Matrix ($Y_{bus}$): Manual entry of the complex matrix elements ($G_{ij} + jB_{ij}$) via a grid-based UI. The user must pre-calculate admittance values from line impedances ($Y = 1/Z$).Bus Specification: Interactive forms to define bus types (Slack, PQ, PV) and state variables.Units: Voltage in p.u., Angles in Degrees (internally converted to Radians), Power in p.u.Current LimitationsSystem Size: Hardcoded limit of 4 Buses (MAX_BUS = 4) due to screen resolution and static memory allocation for the matrix solver.Manual Topology: Does not support line-data entry ($R, X, B_{shunt}$). The user must manually build and input the $Y_{bus}$ matrix.Missing Algorithms: The "Fast Decoupled" and "DC Load Flow" options in the menu are currently placeholders that redirect to the full Newton-Raphson and Gauss-Seidel solvers, respectively. They are not yet mathematically implemented.PV-PQ Switching: Advanced reactive power limit handling (switching a PV bus to a PQ bus when $Q_{lim}$ is violated) is not fully implemented in the Newton-Raphson routine.
